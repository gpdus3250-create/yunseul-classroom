# 새 자연 음성 3종 제작 작업

목표: CosyVoice 3, GPT-SoVITS, MeloTTS의 실제 한국어 음성을 각각 생성하여 받아쓰기 왕국에 연결한다.

## 검증 원칙
- 기존 F1/M1/F2/M2/S1 음성 파일과 사이트 설정은 변경하지 않는다.
- 모델 이름만 추가하거나 브라우저 TTS를 다른 모델인 것처럼 표시하지 않는다.
- 실제 생성된 MP3가 존재하고 재생되는 것을 확인한 뒤에만 사이트 선택 목록에 추가한다.
- 문장 끝 억양, 정상 속도, 또박또박한 발음, 띄어쓰기와 문장부호를 비교한다.

## 파일 배치
- `dictation/voice/COSY3/g01_01.mp3` … `g14_10.mp3`
- `dictation/voice/GPTSOVITS/g01_01.mp3` … `g14_10.mp3`
- `dictation/voice/MELO/g01_01.mp3` … `g14_10.mp3`
- 각 모델의 `intro.mp3`, `outro.mp3`, `n01.mp3` … `n30.mp3`도 필요하다.

## 진행 단계
1. 현재 사이트의 원본 1~14급 문장 140개를 그대로 추출한다.
2. 모델별 한국어 지원, 실행 환경, 이용 조건, 참고 음성 요구 사항을 확인한다.
3. 각 모델로 동일한 문장 3개를 먼저 생성해 직접 비교한다.
4. 품질을 확인한 모델에 대해 전체 문장과 안내 음성을 생성한다.
5. 모든 파일의 재생을 검증한 뒤 사이트 음성 선택 목록에 연결한다.

## 현재 상태
작업 계획만 생성됨. 실제 모델 실행, 음성 생성, 사이트 반영은 **아직 완료되지 않음**.
