# 새로운 한국어 선생님 목소리 · Sohee (39.0)

받아쓰기 왕국 39.0은 기존 네 목소리(F1/M1/F2/M2)를 보존하면서,
한국어 원어민 음색을 갖춘 **Sohee** 모델 음성을 새 선택지 **S1**으로 추가합니다.

- 모델: [Qwen3-TTS-12Hz-0.6B-CustomVoice](https://huggingface.co/Qwen/Qwen3-TTS-12Hz-0.6B-CustomVoice)
- 제공: Qwen Team
- 모델 라이선스: **Apache License 2.0**
- 한국어 화자: `Sohee`
- 생성 방식: 로컬 CPU 음성 합성, MP3 파일을 미리 생성해서 정적 웹사이트에 게시
- 녹음 범위: 원본 받아쓰기 140문항(14급 × 10문항), 시험 시작/종료 안내 및 1~30번 번호 음성(총 172개)
- 콘텐츠 원본: 사용자 제공 2026학년도 초등 1학년 2학기 받아쓰기 급수표
- 개인 명단, 학생 정보, 사용자 데이터는 음성 모델이나 파일에 포함되지 않음

**이 목소리는 합성 AI 음성**이며, 사람 선생님의 실제 육성이거나 특정 교사의 음성을 복제한 것이 아닙니다.
기존 37.0과 38.0 음성 파일은 변형하지 않습니다.
사용자가 한국어 발음·억양을 듣고 최종 목소리를 선택할 수 있게 했습니다.
