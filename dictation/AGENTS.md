# 받아쓰기 왕국 수정과 배포

일반 채팅, Work, 사이트 화면에 남긴 코멘트 등 요청이 시작된 곳에 관계없이 받아쓰기 왕국 수정에는 다음 절차를 적용한다. 사용자가 이번 요청에서 지정한 예외를 우선한다.

- ChatGPT에서 화면을 짚어 수정할 수 있도록 기존 ‘받아쓰기 왕국 45.0 편집본’ Sites 프로젝트와 편집 권한을 유지한다. 수업용 사이트는 이 저장소의 `main` 브랜치와 `dictation/` 경로를 사용한다.
- 양쪽의 최신 상태를 먼저 읽고 요청받은 변경만 각각 적용한다. 편집본 전체를 공개 저장소에 복사하지 않는다. 학생 명단이나 비공개 편집 데이터가 공개 파일에 섞이지 않도록 한다.
- 실제 기능이나 화면을 업데이트할 때는 두 화면의 버전 표시를 맞춘다. 변경 범위에 맞게 확인한 뒤 기존 편집본에 배포하고 GitHub에도 반영한다. 초안만 요청한 경우에는 해당 범위를 따른다.
- GitHub Actions의 ‘Publish classroom playground’에서 해당 커밋의 검사와 Pages 배포가 성공했는지 확인한다. 실패하면 원인을 확인해 수정하고 다시 검사한다. 커밋이나 편집본 배포만으로 수업용 배포 완료를 안내하지 않는다.
- 완료 안내에는 수업용 고정 주소 https://gpdus3250-create.github.io/yunseul-classroom/dictation/ 를 먼저 제공한다. 편집본과 공개 배포 상태를 각각 정확하게 알린다.
- 현재 채팅에서 필요한 편집·배포 도구를 사용할 수 없다면 실제로 수행한 범위를 밝히고, 기존 프로젝트에서 이어갈 수 있도록 안내한다.
