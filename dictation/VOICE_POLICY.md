# 받아쓰기 왕국: 음성 보존 원칙 (최우선)

## 절대 변경 금지 — 37.0 원본 AI 목소리

선생님은 **37.0의 여성 F1, 남성 M1 목소리를 모든 후속 버전에서 반드시 그대로 유지**하도록 요청했습니다.

- `dictation/voice/F1/*.mp3`: 여성 목소리 — **수정/교체/재생성/삭제 금지**
- `dictation/voice/M1/*.mp3`: 남성 목소리 — **수정/교체/재생성/삭제 금지**
- 각각 172개, 총 344개의 오리지널 MP3 파일
- 목소리 선택 UI에서도 항상 F1과 M1을 선택할 수 있어야 함
- 고정 원본 정보: `dictation/voice-lock.json`
- 자동 보호 검사: `node scripts/dictation_voice_lock.cjs`
- GitHub Pages 게시 워크플로와 음성 생성 워크플로 모두 원본 불변 검사를 실행함

## 더 자연스러운 선생님 음성을 추가할 때

- F1/M1의 기존 파일 경로·내용·목소리 선택지를 변경하지 말 것
- 새로운 목소리는 F2, M2 또는 새로운 ID를 사용해서 **별도 MP3 파일과 별도 선택지**로 추가할 것
- 초등학교 1학년 어린이가 받아쓰기 공부를 하기 좋은 **명확한 발음, 부드러운 억양, 과하지 않은 감정, 적당한 말 속도, 쉼표·문장 끝 휴지**를 지향할 것
- 문장부호·띄어쓰기·원본 급수표 문장은 그대로 유지할 것
- 새 목소리가 더 자연스러운지는 실제 소리를 검증한 후 안내할 것
- 새로운 목소리의 추가가 기존 F1/M1 파일을 덮어쓰지 않는지 배포 전 확인할 것

이 문서는 후속 수정 작업에서 반드시 지켜야 하는 사용자 요구사항입니다.
